# Revenue-y-Profit-por-Producto
Se analizaron 177,527 órdenes con revenue total de 51.99 millones y profit de 8.86 millones.  
**Hallazgos clave:**  
- El producto más vendido: *Laptop-Gaming-16GB* con 144,198 unidades y 43.4 millones en revenue.  
- Productos con mayor margen: *Sneakers-Urban-42* y *Vacuum-Pro-Black*.  
- Ticket promedio: 2,080 y cantidad promedio por orden: 7.1.  

**Valor:**  
Este análisis permitio priorizar productos estrella y optimizar campañas de marketing.
